# 11 - Wav2Vec2 and XLS-R ATC playground

> Retrospective reconstruction created from the final notebook/report. It is not claimed to be an original timestamped development artifact; generated metrics require rerunning.

This is the CTC corner: Wav2Vec2 Large, XLS-R 300M, ATCOSIM-only, UWB-only, combined checkpoints, and an optional language-model decoder all get the same basic interface.

## حرف حساب

CTC معمولاً سرراست‌تره: audio می‌ره تو، logits میاد بیرون، بعد greedy یا beam decode. ولی همین سادگی گول‌زننده‌ست؛ مدل ATCOSIM روی صدای تمیز ممکنه ترکوندنی باشه و روی VHF واقعی کم بیاره. پس عددها رو با split خودشون نگه می‌داریم و قاطی نمی‌کنیم.

## محتویات

- `ctc_model_catalog.json` - پنج checkpoint و caveat هر کدام.
- `ctc_transcribe.py` - transcription یک فایل با resample واقعی.
- `compare_ctc_checkpoints.py` - یک WAV، چند مدل، timing و خطای واضح.
- `inspect_ctc_vocab.py` - tokenها، delimiter، blank و اندازه vocab.
- `ctc_lm_decode.py` - greedy در برابر pyctcdecode/KenLM اختیاری.
- دو notebook شلوغ‌تر از قبل برای logits و مقایسه مدل‌ها.

```bash
python ctc_transcribe.py sample.wav --model Jzuluaga/wav2vec2-large-960h-lv60-self-en-atc-uwb-atcc-and-atcosim
python compare_ctc_checkpoints.py sample.wav --catalog ctc_model_catalog.json
python inspect_ctc_vocab.py --model Jzuluaga/wav2vec2-xls-r-300m-en-atc-uwb-atcc-and-atcosim
python ctc_lm_decode.py sample.wav --model Jzuluaga/wav2vec2-large-960h-lv60-self-en-atc-uwb-atcc-and-atcosim
```

Numbers in the catalog are user-supplied model-card notes, not results generated by these files.
